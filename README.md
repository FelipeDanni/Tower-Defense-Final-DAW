# Defensa de la Torre - Examen Final DAW 2026

Videojuego web estilo **Tower Defense** desarrollado como proyecto final para la asignatura **Desarrollo y Arquitecturas Web (UAI)**.

## Características Principales
* **Arquitectura Frontend Pura:** Construido con HTML5, CSS3 (Flexbox responsive) y JavaScript estricto (ES5).
* **Sistema de Niveles y Progresión:** Dos mapas con rutas independientes renderizados mediante matrices bidimensionales.
* **Diversidad de Torres y Enemigos:** Torre Básica y Torre Pesada con distintos rangos/daños; enemigos comunes y Tanques en el Nivel 2.
* **Persistencia con LocalStorage:** Registro del Récord Histórico global y modal con el Historial de las últimas 5 partidas.
* **Audio Integrado:** Música de fondo durante la partida.
* **Formulario de Contacto:** Validaciones mediante Expresiones Regulares (Regex) en JS y envío mediante cliente de correo predeterminado (`mailto:`).

## Estructura del Proyecto
* `index.html` / `contacto.html`: Vistas principales.
* `css/`: Hojas de estilo (`reset.css`, `styles.css`, `game.css`).
* `js/`: Lógica modular (`main.js`, `game.js`, `contacto.js`).
* `assets/audio/`: Recursos multimedia.
